Everquest Raid Gear Compairson

I want to make a website that compares the stat increases on T1 and T2 raid gear from one exspantion to the next.
We should be able to select a class and then select the 2 exspantions we want to compair. There should be T1, T2, and BIS. BIS will be for that exspantion.
The stats we care about are AC, hitpoints, mana, endurance, heroic stats and secondary stats.
We will need to compair exspantion to expantion. Example: LS to ToB
I want the exspantion data from Torment of Velious to Favors of Fortune. We will get these item stats from eqresources. We will referance EQGM for how we get these items. I want a Json created that keeps all these stats.
The website should be formated so that it is easy to read and use; with graphs and % changes to the stat.

I also want to be able to look at weapons and be able to compair them. This is not so much for class as it is to allow the user to see the increases from one expantion to the next. User should be able to select Exspantion and then list the T2 weapon. ( We do not care about T1 weapons. )

The website will be hosted through github pages.
